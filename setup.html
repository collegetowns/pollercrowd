Setup guide

Get your own Poller Crowd connection

Poller Crowd works right away on the shared connection, which handles about 200 people at once across every session using it, worldwide. If you teach big classes, speak to large audiences or use it often, give it a free connection of your own so nobody else’s sessions count against you. There’s nothing to pay and no code to write. Supabase, step by step


    

  1. Go to supabase.com and sign up (GitHub or email).
    2. 

  2. Click New project. Name it something like poller-crowd, set any database password (you won’t need it again) and pick the region closest to you. Wait a minute or two while it sets up.
    3. 

  3. Open Project Settings → API Keys (or click Connect at the top). Copy the Project URL, which looks like https://abcdefgh.supabase.co, and the Publishable key, which starts with sb_publishable_. Older projects call it the anon public key; either works.
    4. 

  4. On the presenter screen, click the gear icon. Choose My own free project, then Supabase. Paste the two values, press Test connection, and when it says Connected, press Save.
    5. 



Nothing to build inside Supabase: Poller Crowd only sends live messages, so there are no tables. Leave Realtime → Settings → Allow public access on (it is by default). These are public keys made for web pages; never paste the secret or service_role key anywhere.



Firebase, step by step


    

  1. Go to the Firebase console and sign in with a Google account.
    2. 

  2. Click Create a project (or Add project). Name it something like poller-crowd. You can turn off Google Analytics and the AI assistant options; Poller Crowd doesn’t use them. Stay on the free Spark plan.
    3. 

  3. In the left menu, open Databases & Storage → Realtime Database (older consoles: Build → Realtime Database) and click Create database. Pick the location closest to you and choose Start in locked mode.
    4. 

  4. Open the Rules tab, delete what’s there, paste the rules below, and click Publish. They let Poller Crowd rooms work and block everything else.

    

    5. 

  5. Open the Data tab and copy the link at the top. It looks like https://poller-crowd-default-rtdb.firebaseio.com or https://poller-crowd-default-rtdb.europe-west1.firebasedatabase.app.
    6. 

  6. On the presenter screen, click the gear icon. Choose My own free project, then Firebase. Paste the link, press Test connection, and when it says Connected, press Save.
    7. 



Firebase may email you that your rules allow public access. That’s expected: phones join without accounts, so rooms have to be open, but only inside the pc area and only in the shapes Poller Crowd uses. Nothing is kept: each room is deleted when you end the session.



Good to know, either way


    

  • Before you present, press Test connection in Settings. If a Supabase project fell asleep, open the Supabase dashboard, pick the project and press Restore.
    • 

  • Students joining your rooms need the QR code or link, which tells their phones where your project is. The room code alone points to the shared connection.
    • 

  • Your setting is saved in your browser on that computer. On a different computer, paste the same values into Settings again.
    • 

  • Share your project with colleagues if you like. Just remember everyone using it shares its limit.
    • 

  • Need data to stay in a particular part of the world, such as the EU, the UK or your own country? Pick that region or location when you create the project. Both services offer locations around the world.
    • 




Path 3. Host your own copy


Poller Crowd is free and open source (MIT license). It’s plain HTML, CSS and JavaScript with no build step, so any website host that serves files will do. Hosting your own copy lets you set the connection once for everyone who uses your site, put it on your school’s or organization’s web address, or change the app.


Download the app (.zip)View it on GitHub


    

  1. Make your free Supabase or Firebase project (Path 2 above).
    2. 

  2. Open js/config.js, the only file you need to edit, and paste your values: supabaseUrl and supabaseKey, or firebaseUrl (leave the Supabase lines empty). Change or clear goatcounterCode and feedbackTo so visit counts and feedback come to you instead of College Towns.
    3. 

  3. Publish the folder. The simplest free option: fork the repository on GitHub, then Settings → Pages → Deploy from a branch → main. Netlify, Cloudflare Pages or your own web server work too. It must be served over https, because phones need a secure page for live connections.
    4. 

  4. Open host.html on your site and present the sample set. Scan the QR code with your phone to check it works.
    5. 



Want an AI assistant to do this part? Use the message in Path 1 and pick “host my own copy”. The README has more detail for developers.
